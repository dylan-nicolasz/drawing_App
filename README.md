# Overview

I developed a browser-based drawing application using TypeScript. The application allows users to draw on a canvas using the mouse, choose different colors, change the brush size, erase parts of the drawing, clear the canvas, and undo previous actions. I also added a save feature that uses asynchronous functions to simulate saving the drawing. 

The project demonstrates TypeScript concepts such as classes, arrays, functions, recursion, asynchronous programming, exception handling, and DOM manipulation.

My purpose for writing this software was to improve my understanding and practical use of TypeScript while building something interactive. I wanted to learn how TypeScript can be used with HTML, CSS, and the Canvas API to create a functional web application. I also wanted to practice organizing code with classes and arrays, managing application behavior with functions, and understanding concepts such as recursion, asynchronous programming, and error handling. This project helped me gain more experience that I can apply to future web development projects.

# Development Environment

{I used Visual Studio Code as my main development tool to write, organize, and compile the project. I also used a web browser to run and test the drawing application and check that the buttons, canvas, and other features worked correctly. I used the terminal to compile the TypeScript files and run the terminal demonstration.}

I used TypeScript as the main programming language. I used TypeScript features such as classes, arrays, functions, recursion, asynchronous functions, and exception handling. For the drawing functionality, I used the HTML Canvas API and DOM APIs to interact with the webpage. I did not use any external libraries.
